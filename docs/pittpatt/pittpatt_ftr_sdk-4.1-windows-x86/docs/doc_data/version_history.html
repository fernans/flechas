Chapter 14. FTR-SDK: Version History

  • Version 4.1 was released in March 2010. Notable changes from v4.0 included:

    • Reduced latent memory usage on Windows
    • Added long path support on Windows
    • Initialization no longer changes the working directory
    • Added applications that illustrate how to create and compare known subject galleries
    • Renamed recognition-compare_gallery to recognition-compare_gallery_templates and moved some of its functionality to the new recognition-compare_gallery_subjects application.
    • Added a known subject gallery as an optional parameter to the recognition-across_tracks application. It overlays names for tracks that match subjects in the known subject gallery, if specified.
    • Subject-to-subject similarity scores are now computed by averaging the top several template match scores in the comparison rather than averaging over all scores.
    • Added more videos and single-face images
    • Fixed segfault caused by requesting similarity matrix from an empty gallery
    • Fixed crash caused when clustering small galleries
    • Fixed issue that caused user input to be ignored under certain circumstances when clustering large datasets
    • Fixed segfault caused by freeing an unflattened object in Windows

  • Version 4.0 was released in February 2010. Notable changes from v3.1 included:

    • Detection speed improvement (via search pruning)
    • Reduced detection memory requirements (in single-threaded detection calls)
    • Frontal landmark speed improvement
    • Template extraction speed improvement
    • Template comparison speed improvement
    • Clustering speed improvement
    • Reduced clustering memory requirement
    • Reduced template size
    • Added ability to specify template extraction type
    • Added multi-gallery clustering
    • Removed template compression
    • Added ability to disable template thumbnails
    • Added ability to store strings in galleries
    • Replaced scale_factor, nominal_width, and nominal_height with dimensions
    • Removed size from landmarks since landmarks are a point-feature
    • Replaced min/max/avg scale factor with min/max/avg dimensions in track summary type
    • Added ability to set max size
    • Added ability to set adaptive min/max sizes
    • Added PPR_MIN_MIN_SIZE and PPR_MAX_MAX_SIZE constants
    • Added function to get the object size from the number of pixels between the eyes
    • Added get functions for all set functions
    • Added 'is enabled' functions to all enable functions
    • The crop object from image function always returns RGB color space
    • Added a function to crop a thumbnail from an image
    • Added functions to read and write objects and tracks to disk
    • Added functions to flatten and unflatten objects and tracks
    • Split pittpatt_detection_tracking.h into pittpatt_detection.h and pittpatt_tracking.h
    • One way to acquire a context: ppr_get_context
    • Changed all ppr_update_ function prefixes to ppr_set_
    • Tracking has to be enabled (instead of getting a tracking context)
    • Enabling shot boundary split into enabling shot boundary and setting the shot boundary threshold
    • Argument order for ppr_set_template_string changed
    • Renamed ppr_get_ranked_subject_list to ppr_get_ranked_subject_list_for_subject
    • Arguments passed to ppr_copy_template_to_gallery changed
    • Renamed ppr_object_suitable_for_recognition to ppr_is_object_suitable_for_recognition
    • Added PPR_ prefix to MAX_CLUSTERING_AGGRESSIVENESS and MAX_TEMPLATE_STRING_SIZE
    • Added functions to overlay text
    • Made sdk_draw_utils.c and moved drawing functions to it
    • Added option to overlay text with object overlays
    • Added option to overlay frame numbers on tracker output
    • Utility functions that used to take line color, type, and thickness now take sdk_draw_utils_line_attributes_type
    • Added functions to time execution speed
    • Added applications: a set of robust and powerful sample applications
    • Added tools: a large set of simple, yet powerful sample programs
    • Raw Image: fixed bug in create image function when color space was set to BGR or ARGB.
    • Raw Image: fixed bug when converting between ARGB and anything else
    • Raw Image I/O: added ability to specify a quality when writing images
    • Raw Image I/O: jpegs read as YUV
    • Video I/O: added ability to encode videos
    • Video I/O: frames returned as YUV
    • Video I/O: non-squared pixels properly handled
    • Video I/O: deinterlaces frames
    • Video I/O: changed ppr_video_ prefix to ppr_video_io_
    • Improved documentation

  • Version 3.1 was released in September 2009. Notable changes from v3.0 included:

    • Templates are now compatible across 32-bit and 64-bit architectures (r6668)
    • Fixed an exception that was raised when comparing a gallery of size 1 to a gallery of size 800 to 2000 or when comparing a gallery of size 2 to a gallery of size 800 to 2000 (r6656)
    • Reduced memory fragmentation on Windows (r6549)
    • Sped up shot boundary detection (r6680)
    • Updated the jpeg, png, and tiff libraries used by Raw Image I/O (r6568)

  • Version 3.0 was released in August 2009. Notable changes from v2.4 included:

    • Added multi-instance recognition
    • Added clustering of templates
    • Added transitive matching of templates
    • Added compression of templates in memory and on disk
    • Added a thumbnail to templates
    • Faster template generation
    • Added flatten and unflatten functions for templates and galleries
    • Added the ability to embed a user-defined string to a template
    • Added the ability to specify the frontal yaw cutoff for a frontal face
    • Added new landmark detection options: PPR_DUAL_FRONTAL_LANDMARK_DETECTOR and PPR_DUAL_MULTI_POSE_LANDMARK_DETECTOR
    • Removed single-pass landmarks
    • Added a function to get the single best frontal face object from an image
    • Added a function to crop an object from an image
    • Added a separate tracking call that allows tracking to be threaded at the frame level
    • Visual instances are no longer rotated and have more padding
    • License manager no longer requires a license file
    • Changed term 'scene break' to 'shot boundary'
    • Changed term 'tracking threshold' to 'tracking cutoff'
    • Changed the ppt_ prefix to ppr_
    • Changed the ppi_ prefix to ppr_raw_image_ (and ppr_raw_image_io_ for I/O functions)
    • Changed the ppv_ prefix to ppr_video_
    • Added a webcam frame-grabber Library for Windows and Linux
    • Added Raw Image Library. The FTR-SDK, Raw Image I/O, and Video Decoding now depend on this library.
    • Removed pittpatt_image_types.h
    • Renamed pittpatt_image_io.h file to pittpatt_raw_image_io.h
    • Renamed sdk_utilities.c/.h files to sdk_utils.c/.h
    • Added SDK utility function to get number of CPUs
    • Added SDK utilities to parse command-line arguments
    • Correctly reporting left and right eye landmarks in multi-pose frontal landmarks (r3936)
    • Improved scene break detection (r5221)
    • Improved speed and stability (r5397)
    • Added ppr_finalize_thread function to prevent memory leak (r6062)
    • No longer providing Visual Studio 6.0 project files
    • Improved documentation: added migration guide, tuning guide, and getting started guide

  • Version 2.4 was released in February 2009. Notable changes from v2.3 included:

    • Improved computational performance in Windows XP (via a custom memory allocator)
    • Improved visual attention
    • Implemented new license manager

  • Version 2.3 was released in December 2008. Notable changes from v2.2 included:

    • Improved multi-pass multi-pose landmark accuracy
    • Updated recognizer
    • Added YUV and BGR color space support to the Image I/O library

  • Version 2.2 was released in September 2008. Notable changes from v2.1 included:

    • Added multi-pass multi-pose landmarks
    • Added shot boundary detection
    • Improved visual attention
    • Improved multi-threaded landmark computational performance
    • Improved computational performance on 64-bit systems
    • Added jpeg2000 and tiff support to Image I/O library
    • Improved error reporting in Video I/O library
    • Added logging functionality to Video I/O for debugging purposes
