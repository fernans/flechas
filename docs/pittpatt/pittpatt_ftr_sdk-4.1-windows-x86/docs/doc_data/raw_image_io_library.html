The PittPatt Raw Image I/O Library is provided for reading and writing images of many different image formats.

It is important to also read the PittPatt Raw Image Library Documentation because the PittPatt Raw Image I/O Library depends on it, and it includes very important information about Memory Management.

1. Introductory Topics

Supported Formats

The PittPatt Raw Image I/O Library supports many image formats including, but not limited to: JPEG, GIF, BMP, PNG, PPM, and PGM.

Back to top.

Image Quality

Two functions are provided for writing a raw image to disk. The ppr_raw_image_io_write_with_quality function has a quality argument used to specify the image quality for lossy formats. The ppr_raw_image_io_write function uses a default quality of 85 and is provided as a convenience function.

For lossy image formats, the quality argument controls the compression ratio, where 0 represents the most compression and 100 represents the highest quality. For non-lossy formats, the quality argument is ignored.

2. Function Reference

The functions described in this section are declared in pittpatt_raw_image_io.h. The main data type used by these functions, ppr_raw_image_type, is declared in pittpatt_raw_image.h, and is described in the PittPatt Raw Image Library Documentation.

ppr_raw_image_io_read

ppr_raw_image_error_type ppr_raw_image_io_read( const char  *file_name,
  ppr_raw_image_type  *image);
Parameters

file_name - null-terminated string specifying the file name of the image to read

image - pointer to a raw image read from the specified file

Returns

error code

Restrictions

none

Reads an image from a file, using the file extension to determine the format. Grayscale images are returned using the PPR_RAW_IMAGE_GRAY8 color space, and color images are returned using the PPR_RAW_IMAGE_RGB24 color space. The image that is read must later be freed using ppr_raw_image_free.

See also: Supported Formats, Color Spaces

Back to top.

ppr_raw_image_io_write

ppr_raw_image_error_type ppr_raw_image_io_write( const char  *file_name,
  ppr_raw_image_type  image);
Parameters

file_name - null-terminated string specifying the file name of the image to write

image - raw image to write to disk

Returns

error code

Restrictions

none

Writes an image to a file, using the file extension to determine the format. Calling this function is equivalent to calling ppr_raw_image_io_write_with_quality with a quality value of 85.

See also: Supported Formats, Image Quality

Back to top.

ppr_raw_image_io_write_with_quality

ppr_raw_image_error_type ppr_raw_image_io_write_with_quality( const char  *file_name,
  ppr_raw_image_type  image,
  int  quality);
Parameters

file_name - null-terminated string specifying the file name of the image to write

image - raw image to write to disk

quality - quality setting to use when writing the output image

Returns

error code

Restrictions

none

Writes an image to a file, using the file extension to determine the format. For lossy image formats the quality argument controls the compression ratio. For non-lossy formats, calling this function is equivalent to calling ppr_raw_image_io_write.

See also: Supported Formats, Image Quality
