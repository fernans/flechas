String Size Constants

PPR_MAX_TEMPLATE_STRING_SIZE

#define PPR_MAX_TEMPLATE_STRING_SIZE 4096

The PPR_MAX_TEMPLATE_STRING_SIZE constant specifies the maximum allowable string length, including the null terminator, that can be passed to ppr_set_template_string or ppr_set_template_string_by_id. The user is ensured that any string returned from ppr_get_template_string or ppr_get_template_string_by_id will not exceed the maximum size, including the null terminator.

See also: Template and Gallery Strings

2. Types Reference

The data types described in this section are defined in pittpatt_recognition.h.

Basic Types

ppr_template_type

typedef struct ppr_template_struct* ppr_template_type;

The ppr_template_type is a representation of a face that can be compared to other templates to determine similarity between two faces. Templates can be created with ppr_extract_template_from_object or read with ppr_read_template. The returned template must later be freed using ppr_free_template.

See also: Templates

Back to top.

ppr_gallery_type

typedef struct ppr_gallery_struct* ppr_gallery_type;

The ppr_gallery_type maintains a list of templates and information about the relationship between templates. A gallery can be created with ppr_create_gallery or read with ppr_read_gallery. The returned gallery must be freed using ppr_free_gallery.

See also: Galleries

Back to top.

ppr_similarity_matrix_type

typedef struct ppr_similarity_matrix_struct* ppr_similarity_matrix_type;

The ppr_similarity_matrix_type is a matrix that gives the similarity between templates in a query gallery and templates in a target gallery. Elements of a similarity matrix can be accessed using ppr_get_similarity_matrix_element. The ppr_get_query_template_id_list_from_similarity_matrix and ppr_get_target_template_id_list_from_similarity_matrix functions can be used to get the IDs of the templates that correspond to the rows (queries) and columns (targets) of the similarity matrix. A similarity matrix must be freed using ppr_free_similarity_matrix.

See also: Similarity Matrices

Back to top.

Enumerated Types

ppr_template_extraction_type

typedef enum 
{
  PPR_EXTRACT_SINGLE,
  PPR_EXTRACT_DOUBLE
} ppr_template_extraction_type;

This enumeration provides a means of specifying how templates should be extracted. Single templates are less accurate than double templates, but they use half of the memory and comparisons are twice as fast. Use ppr_set_template_extraction_type to specify the extraction type.

See also: Template Extraction, Templates

Back to top.

ppr_template_relationship_type

typedef enum 
{
  PPR_RELATIONSHIP_UNKNOWN,
  PPR_RELATIONSHIP_SAME_SUBJECT,
  PPR_RELATIONSHIP_DIFFERENT_SUBJECTS
} ppr_template_relationship_type;

This enumeration provides a means of specifying relationships between templates. A gallery maintains information about template relationships between templates within the gallery.

See also: Template Relationships, Templates

Back to top.

ppr_object_suitability_type

typedef enum 
{
  PPR_OBJECT_NOT_SUITABLE_FOR_RECOGNITION,
  PPR_OBJECT_SUITABLE_FOR_RECOGNITION
} ppr_object_suitability_type;

This enumeration indicates whether an object is suitable for recognition. Templates can only be extracted from frontal face objects with the necessary landmarks. Use ppr_is_object_suitable_for_recognition to determine if an object is suitable for recognition.

See also: Template Extraction, Frontal Yaw Constraint and Templates, Templates

Back to top.

ppr_subject_list_type

typedef struct
{
  int num_subjects;
  ppr_template_id_list_type *subjects;
  int capacity;
} ppr_subject_list_type;

The ppr_subject_list_type represents a list of subjects belonging to a single gallery, where a subject is a list of template IDs. A subject list can be produced from a gallery by calling ppr_cluster_gallery. The subject list must later be freed using ppr_free_subject_list.

int num_subjects

Number of subjects in the list.

ppr_template_id_list_type *subjects

Array of subjects. Each subject is a template ID list giving the IDs of the templates that make up the subject.

int capacity

Number of elements allocated in the array.

See also: Subject Lists, Clustering, Galleries, Templates

object - object to create template for

the_template - pointer to created template

Returns

error code

Restrictions

Context must be initialized

Recognition must be enabled

Object must be a frontal face with required landmarks

Creates a template for the submitted object if the object is suitable for recognition as indicated by ppr_is_object_suitable_for_recognition. ppr_get_template_string_length

ppr_error_type ppr_get_template_string_length( ppr_context_type  context,
  ppr_template_type  the_template,

Parameters

context - handle to context

the_template - template to get string length from

string_length - pointer to length of template string, not including the null terminator

Returns

error code

Restrictions

Recognition must be enabled

Gets the length of the string embedded in the template, not including the null terminator. If the string was not previously set using ppr_set_template_string or ppr_set_template_string_by_id, the length returned will be zero, as the string consists of only the null terminator. The string length is guaranteed to not be larger than PPR_MAX_TEMPLATE_STRING_SIZE - 1.

This function is useful for allocating a string before calling ppr_get_template_string. Remember that the returned length does not include the null terminator, so this must be accounted for by allocating a size that is one more than the value returned from this function.

ppr_get_template_string

ppr_error_type ppr_get_template_string( ppr_context_type  context,
  ppr_template_type  the_template,
  char  *string);
Parameters

context - handle to context

the_template - template to get string from

string - null-terminated string copied from template

Returns

error code

Restrictions

Recognition must be enabled

Gets the string embedded in the template, which was previously set using ppr_set_template_string or ppr_set_template_string_by_id. If the string was not set, a zero-length string is returned, consisting of only a null terminator. The string is guaranteed to not be longer than PPR_MAX_TEMPLATE_STRING_SIZE, including the null terminator. The function does not allocate memory for the output string. The output string must be allocated by the user before calling the function, and it must be large enough to hold the contents of the output string, including the null terminator. The size of the string can be determined beforehand using the ppr_get_template_string_length function, or the user can simply allocate enough memory to hold the maximum possible string size.

See also: Template and Gallery Strings, Templates

Free Functions

The provided free functions must be used to free the data structures returned from SDK functions - the user should not try to free these structures using their own free statements. Likewise, if the user allocates their own memory using the provided data types, the user must free that memory themselves rather than calling these free functions. This ensures that the same libraries are used for allocation and freeing.
