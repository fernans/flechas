The PittPatt Raw Image Library provides a raw image type along with functions to allocate an image, free an image, and convert between image color formats. It is used not only by the FTR-SDK, but also by the PittPatt Raw Image I/O Library and the PittPatt Video I/O Library.

1. Introductory Topics

Memory Management

Memory must be freed using the same library that allocated the memory. Using ppr_raw_image_create to allocate images and ppr_raw_image_free to free images will ensure that the same library is used for allocating and freeing. The PittPatt libraries (the FTR-SDK, the PittPatt Raw Image I/O Library, and the PittPatt Video I/O Library) use ppr_raw_image_create to allocate images internally, and therefore raw images allocated by one of those libraries must be freed using ppr_raw_image_free. If the user allocates their own raw image, then it must be freed using their own free function. Freeing such an image with ppr_raw_image_free can result in failure.

Image Color Spaces

The ppr_raw_image_type structure supports several different color formats. A brief description of the supported formats follows:

  • GRAY8 is used for grayscale images. Each pixel is represented by a single byte (unsigned char) that represents an intensity value (0-255).

  • RGB24 pixels are denoted by three consecutive bytes (unsigned chars) that represent the colors red, green, and blue, respectively (0-255, each).

  • BGR24 pixels are denoted by three consecutive bytes (unsigned chars) that represent the colors blue, green, and red respectively (0-255, each).

  • ARGB32 pixels are represented by a 4-byte integer (unsigned int) in the form of 0xAARRGGBB where RR is red, GG is green, and BB is blue. The alpha channel (AA) is ignored.

  • YUV pixels are represented by three consecutive bytes (unsigned chars) in terms of one luma (Y) and two chrominance (UV) components respectively (0-255, each).

Note

The YUV color space is defined here to be as in the JPEG JFIF standard. This means the dynamic range of all three channels is 0-255. This is not like the YUV common in video formats (which uses a reduced dynamic range).

Note

While it is true that RGB24 will always consist of R, G, B, in that order in memory, this is not true for ARGB32. Since ARGB32 pixels are represented by a single 32-bit integer, the least significant byte of the pixel data will be blue, the next least significant green, and so on. Consequently, the actual byte order in memory is dependent on the endianness of the system. For little endian systems (like x86 based machines), the actual byte order in memory will be B, G, R, A. These endian-related issues can be safely ignored if the array is treated as an unsigned integer array instead of an unsigned character array.

2. Types Reference

The data types described in this section are declared in pittpatt_raw_image.h.

Enumerated Types

ppr_raw_image_color_space_type

typedef enum 
{
  PPR_RAW_IMAGE_GRAY8,
  PPR_RAW_IMAGE_RGB24,
  PPR_RAW_IMAGE_BGR24,
  PPR_RAW_IMAGE_ARGB32,
  PPR_RAW_IMAGE_YUV
} ppr_raw_image_color_space_type;

This enumeration defines the color space of the image in ppr_raw_image_type.

PPR_RAW_IMAGE_GRAY8

The image is stored using an 8-bit intensity format per pixel.

PPR_RAW_IMAGE_RGB24

The image is stored using a 24-bit RGB format per pixel.

PPR_RAW_IMAGE_BGR24

The image is stored using a 24-bit BGR format per pixel.

PPR_RAW_IMAGE_ARGB32

The image is stored using a 32-bit ARGB format per pixel.

PPR_RAW_IMAGE_YUV

The image is stored using a 24-bit YUV format per pixel.

See also: Image Color Spaces

ppr_raw_image_error_type

typedef enum 
{
  PPR_RAW_IMAGE_SUCCESS,
  PPR_RAW_IMAGE_FAILURE,
  PPR_RAW_IMAGE_INVALID_COLOR_SPACE,
  PPR_RAW_IMAGE_UNABLE_TO_READ_FILE,
  PPR_RAW_IMAGE_UNABLE_TO_WRITE_FILE
} ppr_raw_image_error_type;

The ppr_raw_image_error_type provides error code values for functions that return errors. A string version of each error code can be obtained by calling ppr_raw_image_error_message.

Structure Types

ppr_raw_image_type

typedef struct
{
  unsigned char *data;
  int width;
  int height;
  int bytes_per_line;
  ppr_raw_image_color_space_type color_space;
} ppr_raw_image_type;

This structure contains a buffer of raw image data, along with its size and color format.

unsigned char *data

Image data stored in row-major order in the format specified by color_space.

int width

Width of the image in pixels.

int height

Height of the image in pixels.

int bytes_per_line

Number of bytes in a single row. The bytes_per_line is equal to the width times the number of bytes per pixel (determined by the color_space) plus any additional bytes of padding.

ppr_raw_image_color_space_type color_space

The color format of the data.

See also: Image Color Spaces

3. Function Reference

The functions described in this section are declared in pittpatt_raw_image.h.

ppr_raw_image_create

ppr_raw_image_error_type ppr_raw_image_create( ppr_raw_image_type  *image,
  int  width,
  int  height,
  ppr_raw_image_color_space_type  color_space);
Parameters

image - pointer to a raw image type to allocate memory within

width - width of image to create in pixels

height - height of image to create in pixels

color_space - color format of the image data

Returns

error code

Restrictions

none

Assigns all values in the ppr_raw_image_type structure, allocating memory for the data. The number of bytes of data allocated is equal to the width times the height times the number of bytes per pixel, determined by the color_space. The created image must later be freed using ppr_raw_image_free.

See also: Image Color Spaces

ppr_raw_image_convert

ppr_raw_image_error_type ppr_raw_image_convert( ppr_raw_image_type  *image,
  ppr_raw_image_color_space_type  new_color_space);
Parameters

image - pointer to raw image to be converted

new_color_space - desired color format

Returns

error code

Restrictions

Must not be used on an image allocated outside of one of the PittPatt libraries

Converts between any of the possible color spaces. The conversion is done in place and the function takes care of any memory management required.

Note

This function may need to reallocate the raw image data buffer. Because the library that frees memory must be the same library that allocated the memory, this function can only be used with raw images allocated by one of the PittPatt libraries.

See also: Memory Management, Image Color Spaces

ppr_raw_image_free

void ppr_raw_image_free( ppr_raw_image_type  image);
Parameters

image - raw image to free data buffer within

Returns

none

Restrictions

Must not be used to free memory allocated outside of one of the PittPatt libraries

Frees the data buffer in the raw image.

Note

Because the library that frees memory must be the same library that allocated the memory, this function can only be used to free data allocated by one of the PittPatt libraries.
