1. Constants Reference

The constants described in this section are defined in pittpatt_clustering.h.

Clustering Constants

PPR_MAX_CLUSTERING_AGGRESSIVENESS

#define PPR_MAX_CLUSTERING_AGGRESSIVENESS 10

The PPR_MAX_CLUSTERING_AGGRESSIVENESS constant specifies the maximum aggressiveness value that can be passed to ppr_cluster_gallery or ppr_cluster_gallery_group. The minimum allowable aggressiveness is 0.

See also: Clustering Aggressiveness, Clustering, Multi-Gallery Clustering

2. Types Reference

The data types described in this section are declared in pittpatt_clustering.h.

Basic Types

ppr_gallery_group_type

typedef struct ppr_gallery_group_struct* ppr_gallery_group_type;

The ppr_gallery_group_type maintains a set of galleries to be used for multi-gallery clustering. A gallery group can be created with ppr_create_gallery_group or ppr_create_disk_gallery_group. A gallery group can be read with ppr_read_gallery_group or ppr_read_as_disk_gallery_group. The returned gallery group must be freed using ppr_free_gallery_group.

See also: Gallery Groups, Disk Gallery Groups

Back to top.

ppr_template_source_type

typedef struct
{
  int gallery_id;
  int template_id;
} ppr_template_source_type;

The ppr_template_source_type provides a means of specifying an individual template within a gallery group. Since template IDs are not unique between galleries, specifying a single template within a gallery group requires providing not only the template's ID, but also the ID of the gallery that contains the template.

int gallery_id

ID of the gallery within the gallery group that contains the template.

int template_id

ID of the template within the gallery specified by gallery_id.

See also: Template Sources, Gallery Groups

Back to top.

ppr_template_source_list_type

typedef struct
{
  int num_template_sources;
  ppr_template_source_type *template_sources;
  int capacity;
} ppr_template_source_list_type;

The ppr_template_source_list_type structure is used to store a list of template sources, thereby specifying a set of templates within a gallery group. Template source lists can be freed using ppr_free_template_source_list.

int num_template_sources

Number of template sources in the list.

ppr_template_source_type *template_sources

Array of template sources.

int capacity

Number of elements allocated in the array.

See also: Template Sources, Gallery Groups

Back to top.

ppr_inter_gallery_subject_list_type

typedef struct
{
  int num_subjects;
  ppr_template_source_list_type *subjects;
  int capacity;
} ppr_inter_gallery_subject_list_type;

The ppr_inter_gallery_subject_list_type represents a list of subjects spanning multiple galleries in a gallery group, where a subject is a list of template sources. An inter-gallery subject list can be produced from a gallery group by calling ppr_cluster_gallery_group. The inter-gallery subject list must later be freed using ppr_free_inter_gallery_subject_list.

int num_subjects

Number of subjects in the list.

ppr_template_source_list_type *subjects

Array of subjects. Each subject is a template source list.

int capacity

Number of elements allocated in the array.

See also: Inter-Gallery Subject Lists, Template Sources, Multi-Gallery Clustering, Gallery Groups

ppr_get_gallery_string_length_by_id

ppr_error_type ppr_get_gallery_string_length_by_id( ppr_context_type  context,
  ppr_gallery_group_type  gallery_group,
  int  gallery_id,

Parameters

context - handle to context

gallery_group - gallery group containing gallery to get string length from

gallery_id - ID of gallery to get string length from

string_length - pointer to length of gallery string, not including the null terminator

Returns

error code

Restrictions

Recognition must be enabled

Gets the length of the string embedded in the gallery with the specified ID, not including the null terminator. If the string was not previously set using ppr_set_gallery_string or ppr_set_gallery_string_by_id, the length returned will be zero, as the string consists of only the null terminator. ppr_get_gallery_string_by_id

  char  *string);
Parameters

context - handle to context

gallery - gallery group containing gallery to get string from

gallery_id - ID of gallery to get string from

Returns

error code

Restrictions

Recognition must be enabled

Gets the string embedded in the gallery, which was previously set using ppr_set_gallery_string or ppr_set_gallery_string_by_id. If the string was not set, a zero-length string is returned, consisting of only a null terminator. The size of the string can be determined beforehand using the ppr_get_gallery_string_length_by_id function, or the user can simply allocate enough memory to hold the maximum possible string size.

See also: Template and Gallery Strings, Galleries, Gallery Groups

Clustering and Comparison Functions

ppr_cluster_gallery

ppr_error_type ppr_cluster_gallery( ppr_context_type  context,
  ppr_gallery_type  gallery,
  int   clustering_aggressiveness,
  ppr_subject_list_type  *subject_list);
Parameters

context - handle to context

gallery - gallery to cluster into subject list

clustering_aggressiveness - aggressiveness when clustering to generate subject list

subject_list - pointer to generated subject list

Returns

error code

Restrictions

Context must be initialized

Recognition must be enabled

Clusters templates to generate a subject list from a gallery. The subject list is generated with the specified clustering aggressiveness. User-specified template relationships are accounted for when generating the output subject list.

An error is returned from clustering when a paradoxical template relationship is encountered. In this case, the results are invalid and any paradoxes in the template relationships must be corrected before clustering can be performed.

The returned subject list must later be freed using ppr_free_subject_list.

See also: Clustering, Clustering Aggressiveness, Template Relationships, Paradoxical Relationships, Subject Lists, Galleries

Back to top.

context - handle to context

gallery_group - pointer to unflattened gallery group

Returns

error code

Restrictions

none

Unflattens a gallery group by taking data from a flattened buffer and turning it into a regular gallery group. This is useful for applications that must read gallery groups from input sources other than the file system, such as a database. The resulting gallery group must be freed using ppr_free_gallery_group.

ppr_unflatten_as_disk_gallery_group

ppr_error_type ppr_unflatten_as_disk_gallery_group( ppr_context_type  context,
  ppr_flat_gallery_group_type  flat_gallery_group,
  ppr_gallery_group_type  *gallery_group,
  const char  *scratch_directory);
Parameters

context - handle to context

flat_gallery_group - gallery group to unflatten

gallery_group - pointer to unflattened gallery group

scratch_directory - null-terminated string specifying an existing directory to use for intermediate files

Returns

error code

Restrictions

none

Unflattens a gallery group by taking data from a flattened buffer and turning it into a regular gallery group. This is useful for applications that must read gallery groups from input sources other than the file system, such as a database. Unlike ppr_unflatten_gallery_group, this function produces a gallery group in which the galleries are stored on disk (in the specified scratch_directory) and only loaded when needed. The resulting gallery group must be freed using ppr_free_gallery_group.

See also: Flattened Data, Disk Gallery Groups, Disk Gallery Groups

Free Functions

The provided free functions must be used to free the data structures returned from SDK functions - the user should not try to free these structures using their own free statements. Likewise, if the user allocates their own memory using the provided data types, the user must free that memory themselves rather than calling these free functions. This ensures that the same libraries are used for allocation and freeing.
